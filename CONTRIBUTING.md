# 🤝 Contributing Guide

Thanks for your interest in contributing to this project! Whether you're fixing a bug, improving accessibility, writing tests, or suggesting new features — you're welcome here.

---

## 🛠 Local Setup

1. **Fork the repository** and clone it to your machine:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name


- Install dependencies:
- Backend:
cd server
npm install
- Frontend:
cd client
npm install
- Create .env files in both client/ and server/ with the required environment variables (see README).
- Run the app locally:
- Backend: npm run start
- Frontend: npm run dev

🧪 Testing
- Backend Tests:
cd server
npm run test
- Uses Vitest and Supertest with mocked axiosInstance and middleware.
- Frontend Tests: Coming soon — Cypress or Playwright integration planned.
🔁 Pull Request Process- Create a new branch:
git checkout -b feature/your-feature-name
- Make your changes and commit:
git commit -m "feat: add dark mode toggle"
- Push and open a pull request:
git push origin feature/your-feature-name
- In your PR description:
- Explain what you changed and why
- Link any related issues
- Mention if tests were added or updated
🐞 Reporting BugsPlease open an issue with:- ✅ Steps to reproduce
- ✅ Expected vs actual behavior
- ✅ Screenshots or logs (if available)
- ✅ Environment info (browser, OS, etc.)
🎨 Accessibility & UX ContributionsWe especially welcome:- Keyboard navigation fixes
- ARIA role improvements
- Contrast and readability enhancements
- Delightful micro-interactions
📜 Code of ConductWe follow a respectful, inclusive collaboration model. Be kind, constructive, and open to feedback. Harassment, discrimination, or toxic behavior will not be tolerated.🙌 Thank YouYour contributions make this project better for everyone. Let’s build something robust, inclusive, and delightful together!
