# 🎉 Event Registration System

A full-stack web application for managing event registrations, built with the MERN stack. It includes a dynamic registration form, admin dashboard, and event creation flow with file upload support.

> 🚧 This project is currently under development. Core features are functional, and enhancements are in progress.

---

## 🚀 Features

- ✅ User registration form with dynamic fields
- ✅ Admin dashboard to view registrations and events
- ✅ Add new events with banner upload
- ✅ MongoDB integration for persistent data
- ✅ Responsive UI with Tailwind CSS
- ✅ Backend API with Express.js
- ✅ File upload handling using Multer

---

## 🛠 Tech Stack

| Layer       | Technology         |
|-------------|--------------------|
| Frontend    | React.js, Tailwind CSS |
| Backend     | Node.js, Express.js |
| Database    | MongoDB + Mongoose |
| Deployment  | Render (in progress) |
| Tools       | GitHub, Figma, Multer |
