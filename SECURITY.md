## Reporting Vulnerabilities

If you discover a security vulnerability in this project, please **do not open a public issue**. Instead, report it privately to the maintainers.

- 📧 Email: [mtjiff@gmail.com]
- 🕒 Response Time: We aim to respond within **48 hours** and resolve valid issues within **7 days**.

Please include as much detail as possible:
- Steps to reproduce
- Impact assessment
- Suggested fix (if available)

## Supported Versions

We currently support the latest production release. Older versions may not receive security updates.

| Version | Supported |
|--------|-----------|
| Latest | ✅         |
| Older  | ❌         |

## Responsible Disclosure

We appreciate responsible disclosure and will credit you in the changelog and release notes (unless you prefer to remain anonymous).
